# Security and bootstrap presentation

This working draft starts with a picture story: ten cartoon scenes with the same cast (slides 2 to 11), placed before the text walkthrough because the pictures give a first-time viewer the whole story first. The text walkthrough (slides 12 to 27) follows the sandbox administrator through installation, normal operation and recovery. The final four slides present recommendations for decisions that remain open. The proposal describes intended behavior; implementation is pending.

The source is `deck.md`. `sources.md` records the operator decisions, references, design gaps and the status of the recommendations. The picture-story scenes show the current custody model: the machine stores one encrypted copy per enrolled passkey. Earlier drafts, which describe an older custody model, are not part of this folder.

Build the HTML and PDF from this directory:

```sh
python3 build.py
chrome-headless-shell --no-pdf-header-footer --print-to-pdf="$PWD/security-and-bootstrap.pdf" "file://$PWD/deck.html"
```

A local Chrome or Chromium installation can print the PDF. Some environments require a separate user-data directory and browser permissions.

The picture-story scenes are generated by `illustrations/make-scenes.py` (Python 3 standard library). Regenerate them and the PNGs with:

```sh
cd illustrations
python3 make-scenes.py
for f in *.svg; do rsvg-convert -w 1800 "$f" -o "${f%.svg}.png"; done
```
