# ADR-0003 archive: EBU DMF V2.0 layer/vertical/lifecycle taxonomy

This file holds material moved out of [ADR-0003](../../decisions/0003-ebu-v2-taxonomy.md) when the ADRs were cut to a short shape. The text is unchanged apart from headings and relative link paths. The ADR is the binding record; this file is history and is not maintained.

## Alternatives considered

- **Keep ad-hoc phase numbering.** Loses the credibility/OSS leverage of EBU
  alignment.
- **Adopt only the layer scheme, not verticals.** The verticals are where
  cross-cutting concerns live (security, monitoring); without them, those
  concerns end up scattered. Adopting half is worse than adopting all.
