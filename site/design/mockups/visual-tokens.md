# Shared visual tokens for the mockups

Use these values across the homepage and sponsorship mockups so the two pages read as one dmfdeploy site.

| Token | Value | Use |
|---|---|---|
| Canvas | `#071017` | Main background |
| Raised canvas | `#101d25` | Content plates and media captions |
| Grouped canvas | `#152832` | Status and caution panels |
| Paper | `#f4f2ee` | Main text and primary button face |
| Muted text | `#a8b8bc` | Supporting copy |
| Aqua | `#70d7ca` | Links, implemented path and demonstrated state |
| Amber | `#e6b26e` | Proposed, pending and caution states |
| Fine rule | `#30434b` | Semantic dividers |
| Hero gradient | `linear-gradient(112deg, #a83173 0%, #cb477f 31%, #e56f72 65%, #ed925d 100%)` | One warm entry field on each page |

Typography: `Inter, "Avenir Next", system-ui, sans-serif`; body copy 16px with 1.55 line height; headings use sentence case and tight tracking; essential status and metadata is at least 14px. Content uses a maximum width near 1180px with 26px desktop gutters and 19px mobile gutters.

Shape and focus: 3px default corners for buttons and ordinary panels; the film frame may use a deliberately softened outer corner. Use low contrast 1px rules to group related information. Keyboard focus is a 3px visible outline with 4px offset. No freestanding ellipse ornament.

Both standalone mockups should use the same compact mobile header: always-visible Sponsor action and a Menu button that opens Project, Architecture, Status and Sponsor links in a readable panel.
