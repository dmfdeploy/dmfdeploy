# dmfdeploy documentation

This folder holds the knowledge base for the dmfdeploy platform. Code lives in
the component repos; the umbrella keeps the decisions, plans, and runbooks that
explain it.

## Where to start

1. [THESIS.md](THESIS.md) says what the platform claims and what a newcomer can
   check.
2. [JOURNEY.md](JOURNEY.md) tells how the project got here.
3. The [Start here list](decisions/INDEX.md#start-here) names the core
   decisions, in reading order.
4. [OPEN-QUESTIONS.md](OPEN-QUESTIONS.md) lists what is frozen, unproven, or
   undecided.

For what comes next, see the [roadmap](../ROADMAP.md). To contribute, see
[CONTRIBUTING.md](../CONTRIBUTING.md).

## What lives where

| Folder | What it holds |
|---|---|
| [decisions/](decisions/INDEX.md) | Architecture decision records (ADRs) and the [RFC process](decisions/README.md) that proposes them. |
| [plans/](plans/INDEX.md) | Design plans for tracked issues, grouped by status in a generated index. |
| [runbooks/](runbooks/) | Step-by-step operating procedures, such as the [demo journey](runbooks/dmf-demo-journey.md). |
| [architecture/](architecture/) | Long-lived design documents, such as the [Platform Plan](architecture/dmfdeploy-platform-plan.md). |
| `archive/` | Superseded plans, reviews, and records, kept for history. |

The full map of every folder, with the rules for each kind of document, is in
[INDEX.md](INDEX.md). How issues, milestones, and documents fit together is in
[WORKING-MODEL.md](WORKING-MODEL.md), and the writing style is in
[STYLE.md](STYLE.md).
