# ADR-0041 archive: DMF Release and Contribution Model

This file holds material moved out of [ADR-0041](../../decisions/0041-release-and-contribution-model.md) when the ADRs were cut to a short shape. The text is unchanged apart from headings and relative link paths. The ADR is the binding record; this file is history and is not maintained.

## Alternatives considered

1. **Keep Forgejo-canonical + GitHub mirror** — rejected: the GitHub org is now the public collaboration surface; maintaining Forgejo as canonical adds operational complexity without benefit.
2. **CLA instead of DCO** — rejected: DCO is lighter-weight, requires no legal overhead, and is standard for infrastructure projects of this scale.
