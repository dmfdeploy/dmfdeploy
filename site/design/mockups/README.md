# Sponsorship mockup

`sponsor-operational-loop.html` is a standalone design mockup for the founding sponsorship page. It uses the site's current brand mark and an operational-loop visual direction: a warm entry field, a practical status panel, section-by-section funding brief, and connected rows for the proposed annual levels.

Open the HTML file directly in a browser, or use `/design/mockups/sponsor-operational-loop.html` when the local static preview server is running. The brand and primary navigation link to the sibling `homepage.html` mockup so the pair can be reviewed together. The screenshots are captured with Playwright at 1440px desktop and 390px mobile widths.

The current revision follows the independent design review: homepage gradient and type tokens, square 3px actions, shared focus treatment, the homepage's Sponsor action and accessible Menu panel on mobile (including Escape-to-close), a wrapping section index, and no clipped hero or secondary purple field. This remains a design artifact; it does not enable payments or change the production page.

The proposed €1,000, €5,000, €15,000 and €25,000+ levels are labeled as proposals. The fiscal host is unconfirmed, no payment facility is active, corporate invoicing is not confirmed, and inquiries are directed to email only.
