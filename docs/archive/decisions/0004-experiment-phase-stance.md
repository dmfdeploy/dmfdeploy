# ADR-0004 archive: Experiment phase, not hardening

This file holds material moved out of [ADR-0004](../../decisions/0004-experiment-phase-stance.md) when the ADRs were cut to a short shape. The text is unchanged apart from headings and relative link paths. The ADR is the binding record; this file is history and is not maintained.

## Alternatives considered

- **Mode A (harden now, experiment later).** Was the implicit default until the
  2026-04-30 strategic review. Reframed: hardening adds soft lock-in and
  doesn't test the thesis. Retracted.
- **Mode B (parallel hardening + experimentation).** Half-effort on each, neither
  ships. Solo-developer constraint makes serial focus the better bet.
