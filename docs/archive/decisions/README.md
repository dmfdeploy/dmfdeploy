# docs/archive/decisions/

Each file here is the companion record of one ADR in
[docs/decisions/](../../decisions/INDEX.md), under the same file name. When the
ADRs were cut to a short shape (Context, Decision, Consequences, Status), the
material that explains how a decision was reached moved here: alternatives
considered, deliberation, review notes, option matrices, implementation plans
and long background.

- **The ADR is binding.** This directory is history. If an archive file and its
  ADR disagree, the ADR wins.
- **Text is unchanged.** The moved text is verbatim. Only headings and relative
  link paths were adjusted for the new location.
- **Not maintained.** Archive files are not updated when an ADR is amended.
